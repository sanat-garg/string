# Top 5 Websites

## Description

This simple web application displays a list of the top 5 most popular websites in the world. It's built with HTML, CSS, and vanilla JavaScript for a lightweight and responsive experience. The application fetches and displays website data directly within the browser, ensuring it's fully self-contained.

## Features

*   Displays the top 5 websites with links.
*   Modern and clean design.
*   Responsive layout for optimal viewing on different devices.
*   Fully functional and self-contained (no external dependencies).

## How to use

1.  Clone the repository to your local machine.
2.  Open `index.html` in your web browser.

   OR

3. Host the project on a web server or using GitHub Pages to make it accessible online.

## Technologies used

*   HTML5
*   CSS3 (embedded)
*   JavaScript (vanilla)
